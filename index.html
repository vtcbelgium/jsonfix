Frequently asked questions

Why did my JSON fail to parse?

JSON is stricter than JavaScript or Python. A parser rejects the whole document at the first rule it breaks, such as a comma after the last item, a property name without double quotes, a string in single quotes, or a literal like True instead of true. A missing bracket or an unterminated string stops it too.

How does JSONFix repair broken JSON?

JSONFix first tries to parse your input as it is. If that fails, it applies a series of targeted text fixes, parses the result again, and shows the repaired JSON neatly formatted. If the input still cannot be parsed, it shows the parser error instead of guessing at your data.

Does my data get sent to a remote server?

No. JSONFix is 100% private: repair, formatting and validation all run in your browser with client-side code. Your JSON is never uploaded, and the site uses no cookies or analytics.

What syntax errors are automatically repaired?

JSONFix repairs trailing commas in objects and arrays, unquoted keys, single quotes around strings and keys, Python literals (True, False and None), and a trailing semicolon at the end of the input.
